# Waru Edition — Generals Mobile Online

Cinematic, responsive landing page for the Waru Edition / Generals Mobile Online community.

## Features
- Uzbek-first landing page with a dark tactical visual style
- Responsive mobile navigation
- Animated radar, custom SVG tank illustration, glow accents and scroll reveals
- Feature, project, download-links and community sections
- Accessible labels and reduced-motion support
- No framework or build step required

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push to the `main` branch. The workflow in `.github/workflows/pages.yml` publishes the site.
4. When the workflow succeeds, open the Pages URL shown in repository settings.

## Important
The download section intentionally links to the project repository and community until a verified APK/release URL is supplied. Replace those links with the official release URL when it is ready.
